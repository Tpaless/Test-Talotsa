# ฟอนต์บทสนทนาภาษาไทย

`NotoSansThai.ttf` มาจากโครงการ [Google Fonts / Noto Sans Thai](https://github.com/google/fonts/tree/main/ofl/notosansthai) ใช้สำหรับข้อความภาษาไทยใน `ui/dialogue_overlay.tscn` โดยเฉพาะ ใบอนุญาต SIL Open Font License อยู่ใน `OFL.txt`

ถ้าเปลี่ยนฟอนต์ ให้แก้ `Theme Overrides > Fonts` ของ `Speaker`, `Body`, `Counter` และ `NextHint` ในฉากบทสนทนา แล้วทดสอบอักษรไทยบนเครื่องเป้าหมาย
