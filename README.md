# Test Talotsa

เวอร์ชันปัจจุบัน: **v0.8.0-beta.1** (0.8 Beta 1)

เกมยานยิงใต้น้ำ 2D แนวตั้งที่สร้างด้วย Godot ผู้เล่นคือ Johny เต่าทะเลที่ใช้คลื่นชำระล้างช่วยเพื่อนจาก Micro Plastic Energy มีหน้า Home สำหรับเลือกยาน 5 แบบ ด่านเนื้อเรื่อง 1–6 โหมด Endless ระบบคะแนน พลังชีวิต และพื้นหลัง Parallax

## สิ่งที่ต้องติดตั้ง

- [Godot Engine](https://godotengine.org/download/) เวอร์ชัน **4.7.2 Stable** หรือ Godot 4.7 รุ่นที่ใหม่กว่า
- Git สำหรับดาวน์โหลดและทำงานร่วมกับ repository

โปรเจกต์ไม่มี dependency, plugin หรือ Asset ภายนอกที่ต้องติดตั้งเพิ่ม

## ดาวน์โหลดและเปิดโปรเจกต์

```bash
git clone https://github.com/Tpaless/Test-Talotsa.git
cd Test-Talotsa
```

จากนั้น:

1. เปิด Godot Project Manager
2. กด **Import**
3. เลือกไฟล์ `project.godot` ในโฟลเดอร์ที่ clone มา
4. รอ Godot import Asset ครั้งแรก
5. กด **F6** หรือ **F5** เพื่อเล่น

โฟลเดอร์ `.godot/` จะถูกสร้างใหม่บนแต่ละเครื่องอัตโนมัติและไม่ถูกเก็บใน Git

- `[AdminTest]` บนหน้า Home ให้กดคีย์บอร์ด `↑ ↑ ↓ ↓ ← →` ตามลำดับ แล้วกด **START** หนึ่งครั้งเพื่อปลดล็อกตัวละคร ด่าน และ Quest ทั้งหมด พร้อมตั้ง Endless Best Score เป็น 30,000 และ Coin เป็นอย่างน้อย 999 สำหรับทดสอบ

- แตะ/คลิก **BACK** หรือกด Escape เพื่อกลับหน้า Home

### ระหว่างเล่น

- ลากนิ้วบนจอสัมผัส: เคลื่อนที่ตามการลากด้วยความเร็วสูงสุดจากค่า `speed` ของยานที่เลือก
- คลิกซ้ายหนึ่งครั้งเพื่อเลือกการควบคุมด้วยเมาส์ แล้วเลื่อนเมาส์เพื่อขยับยาน; คลิกซ้ายค้างแล้วลากก็ได้ ความเร็วสูงสุดใช้ค่า `speed` ของยานที่เลือก
- `WASD` หรือปุ่มลูกศร: เคลื่อนที่ด้วยคีย์บอร์ด และหยุดให้เมาส์ควบคุมจนกว่าจะคลิกซ้ายอีกครั้ง
- Player และบอสจะเอียงตามทิศซ้าย–ขวาเล็กน้อยขณะเคลื่อนที่ และ Player จะมีภาพซ้อนโปร่งใสตามหลังเพื่อสื่อความเร็ว
- กด `Shift` ค้างขณะขยับด้วยคีย์บอร์ดหรือเมาส์: ลดความเร็วลงเหลือ 42% เพื่อหลบกระสุนได้ละเอียดขึ้น บนมือถือให้กดปุ่ม **SLOW** มุมล่างซ้ายค้างด้วยอีกนิ้ว; วงรอบยานแสดงขอบชนขณะใช้โหมดนี้
- ยานยิงอัตโนมัติระหว่างเล่น
- กด `E` หรือ `Space`, ดับเบิลคลิกซ้าย หรือแตะจอสองครั้งติดกัน เพื่อใช้ท่าพิเศษของ Johny Saparrow, Pichu Johny, Santa Johny หรือ Straw Hat Johny บนมือถือแตะปุ่ม **SPECIAL** มุมล่างขวาก็ได้ ตัวเลขบนปุ่มคือเวลาคูลดาวน์ที่เหลือ
- แตะ/คลิกปุ่ม **PAUSE** หรือกด P: หยุดเกมชั่วคราว
- HUD ใช้แถบเรียกบอสแนวตั้งติดขอบซ้ายโดยไม่มีข้อความกำกับในรอบปกติ; Stage 1 ครั้งแรกจะแสดงคำสอนชั่วคราว ส่วน HP บอสแสดงติดกับตัวบอสโดยตรง
- แต่ละ Stage เป็นบอสตัวเดิม 3 Phase สะสมคะแนน 5,000 ต่อเกจเพื่อเริ่มการต่อสู้แต่ละ Phase เมื่อชนะต้องอ่านบทสนทนาและคำใบ้จุดอ่อนให้จบก่อนจึงไป Phase ถัดไป
- บอสทุกด่านมีสกิลต่างกันและมี 3 ช่วง: เมื่อ HP เหลือ 75% จะเคลื่อนที่และยิงถี่ขึ้น; เมื่อเหลือ 50% จะชาร์จท่าพิเศษ มีวงสีทองเตือนก่อนปล่อยกระสุนเป็นวง และใช้ซ้ำเป็นระยะ ด่านสูงขึ้นเพิ่มศัตรูหนัก จำนวนกระสุนบอส และลดคูลดาวน์ท่าพิเศษ
- กุ้งปล่อย Wave กระสุนสลับฟันปลาจากบนลงล่างเป็นเวลา 5 วินาที ใน Phase 3 จะลาดตระเวนด้านบน พุ่งไปยังตำแหน่งล่าสุดของ Player ผลักผู้เล่นตามทิศพุ่ง กลับจุดเริ่มสกิล แล้วพัก 2 วินาที
- เสและนาใช้ PNG แยก 4 ภาพและเคลื่อนที่แยกกัน Phase 1 ยิงเลเซอร์ X, Phase 2 เพิ่มม่านแสงสีรุ้งแนวตั้งสลับช่องหลบ และ Phase 3 ยิง SENAHOY_Bullet.png ช้า 4 ลูกจากซ้าย–ขวาเมื่อ HP เหลือ 50%
- Plastic Man มี HP ลดลง 20% และแบ่งพลังชีวิตเป็น 5 ช่วง แต่ละช่วงสุ่มรับสกิลไม่ซ้ำจาก Thomas, Khram, Kung, Se-Na และ Lens พร้อมสุ่มจังหวะใช้สกิล
- Thomas, Khram และหมึกเลนส์ใช้ Sprite PNG ล่าสุด โดยหนวดของหมึกเลนส์โจมตีจากด้านข้างด้วย PNG เฉพาะตัว ส่วนเกราะ Phase 3 แสดงเป็นกำแพงหนวด PNG จากขอบซ้ายและขวา
- บอสจะปล่อยยาฟื้น HP ทุกครั้งเมื่อ HP ผ่าน 75%, 50% และ 25%; การฆ่าศัตรูที่มี Tag `Boss` ให้ 1 Coin ทั้ง Story และ Endless จึงได้ 3 Coin เมื่อจบ Story ครบ 3 Phase และหลัง Phase 3 จะได้รับบันทึกแห่งพลังประจำ Stageเข้า Quest Archive
- งานวิจัยอิง `PROJECT _ DESIGN/TEE MAR.md` และเรียงรางวัลตาม Stage เป็น 5, 1, 3-A (กุ้ง), 2, 3-B (หมึกและสัตว์อื่น) และ 4; งานวิจัย 3 ฉบับเต็มจะอ่านได้เมื่อเก็บชิ้นส่วน 3-A และ 3-B ครบ
- Nightmare เพิ่ม HP และความรุนแรงของบอสเป็น X2/X3; Story Nightmare เป็นการเล่นรวดเดียว Stage 1–6 เมื่อตายจะเริ่มใหม่ที่ Stage 1 ส่วน Endless Nightmare มี Score Board แยกจากโหมดปกติ
- แถบ HP แสดงเป็นเปอร์เซ็นต์ ยาฟื้น HP เติม 25% ของ HP สูงสุด ศัตรูทั่วไปทำดาเมจ 5 / 12 / 25 ตามชนิด และบอสทำดาเมจ 20% ของ HP สูงสุด โอกาสศัตรูทั่วไปดรอปยาคือ 15%, 17.5%, 20%, 22.5%, 25% ตามด่าน
- หลังบทสนทนาของบอส Phase 3 จบ เกมจะแสดงผลเคลียร์ Stage และคะแนน
- เมื่อชนะหรือพลังชีวิตหมด เกมแสดงสรุปคะแนน 6 วินาทีแล้วกลับเมนูอัตโนมัติ แตะหน้าจอหรือกด `R` เพื่อกลับทันที

| Johny | สองนัดตรง | 440 | 150 | ไม่มี |

| Pichu Johny | กระสุนพัดกว้าง 5 นัด; ดาเมจบอสลดลง | 318 | 100 | เลเซอร์ 5 เส้นที่ตามการเคลื่อนที่ของยาน ดาเมจเพิ่ม 50% จากท่าเดิม; คูลดาวน์ 7 วินาที |
| Santa Johny | สองนัดตรงแต่ยิงช้ากว่า Johny | 440 | 100 | Beyblade ขนาดใหญ่หมุนเร็วพร้อมภาพซ้อนโปร่งใสเป็นหาง เคลื่อนที่ตรงและสะท้อนเมื่อโดนศัตรู/ขอบจอ; เมื่อโดนบอสจะไปขอบแล้วกลับมา; อยู่ 6 วินาที คูลดาวน์ 8 วินาที |
| Straw Hat Johny | กระสุนใหญ่สองข้างเป็นรูป V ขนาดใหญ่ขึ้น 40% | 440 | 120 | ภาพ `Viper_Skill.png` ยืดจากตัวยานเป็นเวลา 3 วินาที; บอสเสีย HP สูงสุด 25%, 15%, 10% ตามลำดับ รวม 50%; คูลดาวน์ 12 วินาที |

เกมใหม่ปลดล็อกเฉพาะ Johny โดยตัวอื่นใช้เงื่อนไข Coin, ด่านพิเศษ Razor หรือคะแนน Endless 30,000 ตามที่อธิบายในหน้า Home

`speed` คือความเร็วเคลื่อนที่, `fire_delay` คือวินาทีระหว่างยิง (ค่ายิ่งมากยิ่งช้า), `bullet_speed` คือความเร็วกระสุน, `health_multiplier` คือเปอร์เซ็นต์ HP ส่วน `special_cooldown` คือเวลารอก่อนใช้ท่าซ้ำ ค่าเฉพาะท่า เช่น `special_duration`, `special_interval`, `special_pierce`, `laser_count`, `beam_width` และดาเมจ `special_damage` ก็อยู่ในรายการของยานลำนั้น ค่า HP แสดงเป็นจำนวนเต็มโดยปัดขึ้น

## เปลี่ยนภาพตัวละคร

Scene ของยานและศัตรูอยู่ใน `characters/` ส่วน Texture อยู่ใน `assets/sprites/`

ตั้ง path ของภาพยาน ศัตรู กระสุน และไอเทมใน [`scripts/visual_config.gd`](scripts/visual_config.gd) ได้โดยตรง ส่วนภาพท่าพิเศษกำหนดแยกกับท่านั้นใน [`scripts/player_config.gd`](scripts/player_config.gd) ด้วย `special_texture` และ `special_texture_size` ถ้า path ของยาน/ศัตรูว่าง เกมจะใช้ Texture จาก Scene เดิม ซึ่งเปลี่ยนได้โดยเปิด Scene แล้วเลือกโหนด `Sprite2D` จากนั้นลาก PNG, WebP หรือ SVG ใหม่ใส่ช่อง **Texture** ภาพในเมนูเลือกยานจะตรงกับภาพที่ใช้เล่น รายละเอียดอยู่ใน [`assets/sprites/README.md`](assets/sprites/README.md)

## เพิ่มพื้นหลัง Parallax

วางภาพพื้นหลังใน `assets/backgrounds/` แล้วคัดลอกบล็อก Layer ภายใน `LAYER_CONFIGS` ที่ไฟล์ `scripts/parallax_background.gd` ภาพพื้นหลังเดิมขนาด `960 × 540` ยังใช้ได้ โดย Layer ด้านหน้าจะย่อให้พอดีกับความกว้าง `540` และวนซ้ำในแนวตั้ง

```gdscript
{
	"layer": 4,
	"texture": "res://assets/backgrounds/layer_4_dust.png",
	"speed": 70.0,
	"opacity": 1.0,
	"enabled": true
},
```

เลข Layer น้อยอยู่ไกลกว่าและถูกวาดก่อน ความเร็วต่ำทำให้ภาพดูอยู่ไกล รายละเอียดเพิ่มเติมอยู่ใน [`assets/backgrounds/README.md`](assets/backgrounds/README.md)

## ทดสอบแบบ Headless

รันจากโฟลเดอร์โปรเจกต์ โดยเปลี่ยนคำสั่ง `godot` ให้ตรงกับชื่อ executable บนเครื่อง:

```bash
godot --headless --editor --import --path .
godot --headless --path . --script res://tests/smoke_test.gd
```

ผลสำเร็จจะแสดงข้อความ:

```text
SMOKE TEST PASSED: seven PNG bosses, กุ้ง, animated dialogue, audio settings, Viper sprite skill, Nightmare and Web readiness
```

## โครงสร้างหลัก

```text
assets/       ภาพตัวละครและพื้นหลัง
characters/   Scene ของผู้เล่นและศัตรู
scripts/      ระบบเกม, HUD และ Parallax
skills/       สกิลแบบ Resource ที่เลือกใส่ให้ตัวละครได้
ui/           ฉากและคู่มือบทสนทนา
tests/        Smoke test
main.tscn     Scene เริ่มต้น
project.godot การตั้งค่าโปรเจกต์
```

## Export ขึ้น itch.io

โปรเจกต์มี Web preset สำหรับ Browser ทั้งมือถือและ PC แล้ว อ่านขั้นตอนติดตั้ง Godot Web Export Template, สร้างไฟล์ และตั้งค่า itch.io ได้ที่ [คู่มือ Web Export](docs/WEB_EXPORT.md)
